# SAHJONY Global Trade OS

Private import-export operating system for governed worldwide trade execution.

## Core workspaces
- `/owner` — executive command center
- `/employee` — employee operations
- `/customer` — customer portal
- `/owner/countries` / `/employee/countries` — country and corridor activation governance
- `/owner/cuba-desk` / `/employee/cuba-desk` — Cuba Authorized Trade Desk for lawful U.S. → Cuba transactions

## Cuba operating model
`CU` is the real current-law Cuba jurisdiction and remains `LIVE/LIMITED` while present sanctions/export-control restrictions apply. `XCU` is a hypothetical future-state planning scenario and cannot execute live transactions.

The Cuba Authorized Trade Desk supports individual employee assignment, government-authorization evidence, product classification, end-user/end-use review, restricted-party screening, payment-path controls, documents, logistics, recordkeeping, owner release approval and audit evidence. Employees cannot self-release a Cuba transaction.

Current U.S. legal requirements must always be verified against authoritative sources and transaction-specific facts before release. The software does not create or expand any government authorization.
