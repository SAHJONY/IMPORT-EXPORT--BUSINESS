# Cuba Vehicle Export Department — Operational Checklist

Before any shipment is represented as executable:

- [ ] VIN, year, make, model captured
- [ ] Title / ownership evidence verified
- [ ] Used-vehicle CBP export requirements cleared where applicable
- [ ] EEI filed and ITN captured
- [ ] EAR classification documented
- [ ] BIS authorization basis documented
- [ ] OFAC/CACR authorization basis documented
- [ ] Restricted-party screening clear
- [ ] Cuban importer eligibility verified
- [ ] End-user/end-use eligibility verified
- [ ] Carrier accepts Cuba route and vehicle type
- [ ] Dangerous-goods review complete for EV/PHEV/hybrid where applicable
- [ ] Commercial documents complete
- [ ] Cuban customs/import-readiness evidence complete
- [ ] Full landed-cost model complete
- [ ] Customer quote labeled correctly as indicative or firm
- [ ] Chairman review completed before any binding release
