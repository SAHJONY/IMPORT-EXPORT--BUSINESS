# Cuba Vehicle Export Department — PR Summary

This branch creates a dedicated, fail-closed Cuba vehicle export operating department for US-origin vehicle shipments to Cuba.

Key controls:
- BIS/EAR authorization basis is mandatory.
- OFAC/CACR authorization is reviewed separately.
- Used-vehicle CBP/AES requirements are explicit.
- EV/PHEV/hybrid shipments require dangerous-goods review.
- Cuban importer eligibility and customs readiness are mandatory.
- Carrier acceptance is mandatory.
- No automatic legal clearance, booking, payment, shipment release, or binding commitment.
- All completed cases still require owner review.

The department is mounted under the existing Cuba Trade Desk API and registered in the Cuba country bureau configuration.
