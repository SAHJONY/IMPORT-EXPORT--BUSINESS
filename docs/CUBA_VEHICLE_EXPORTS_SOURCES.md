# Regulatory source register — Cuba vehicle exports

Use primary sources before releasing any transaction.

- BIS Cuba export controls: https://www.bis.gov/licensing/country-guidance/cuba-export-controls
- EAR Part 746, Cuba: https://www.bis.gov/regulations/ear/746
- EAR Part 740, license exceptions including SCP: https://www.bis.gov/regulations/ear/740
- OFAC Cuba sanctions program: https://ofac.treasury.gov/sanctions-programs-and-country-information/cuba-sanctions
- OFAC Cuba General License / FAQs: https://ofac.treasury.gov/faqs/added/2026-05-07
- CBP motor-vehicle export requirements: https://www.cbp.gov/trade/basic-import-export/export-docs/motor-vehicle

Operational rule: this register is evidence guidance, not an automatic legal determination. The exact vehicle, end user, end use, ownership/title evidence, authorization basis, route, carrier and Cuban importer must be verified for each case before booking or representing the shipment as executable.
